# Audio fixtures

Real audio, committed, because `--check` (D-W10) and CI both need to run the pipeline
without a microphone, and because a silent clip is the only way to test "heard nothing"
automatically.

All three are **16 kHz mono 16-bit PCM WAV**, which is what `readWavFile` accepts and
nothing else. There is no resampler outside the capture renderer (D-W6), so a fixture at
another rate is a broken fixture and is rejected rather than quietly converted.

| file | what | length | peak |
|---|---|---|---|
| `uzbek-0001.wav` | Uzbek speech | 2.77 s | 0.5153 |
| `english-pangram.wav` | English speech | 2.50 s | 0.8095 |
| `silence-room-tone.wav` | a quiet room | 1.00 s | 0.0040 |

205 KB in total.

## `uzbek-0001.wav`

Clip `0001` of `OvozifyLabs/asr_evaluate_set`, copied byte for byte from
`Scripts/measure/fixtures/0001.wav`, which this repository already ships under Apache-2.0
for the WER harness. Its reference transcript is committed beside it in
`Scripts/measure/data/refs.json`:

> put menyusi oʻzgacha boʻladi

So a `--check` run on this clip has a ground truth to compare against, and the same clip
is one of the three the macOS latency table in `Scripts/measure/README.md` is quoted from.

## `english-pangram.wav`

"The quick brown fox jumps over the lazy dog", synthesised locally with macOS `say -v
Samantha` and converted with `afconvert`. Synthetic rather than recorded because nobody on
this project has a quiet room and a microphone they can commit the output of, and a
pangram rather than a sentence because what it has to exercise is the English path
existing at all, not English accuracy — that is measured elsewhere, on real corpora.

## `silence-room-tone.wav`

One second of low-level noise at peak 0.004, generated by a fixed-seed LCG so it is byte
identical on every machine.

**Deliberately not digital zero.** Zero samples are what a *broken microphone* produces,
and the session's two gates depend on telling that apart from the user's silence: an empty
buffer is a `captureFailed` ("the microphone delivered no audio at all — not a quiet room,
nothing arrived"), and a non-empty buffer whose peak is under 0.012 is `heardNothing`. A
fixture of pure zeros would test the first path while claiming to test the second, which
is precisely the confusion that once told a user with a dead audio graph, seven times in
one session, that they had said nothing.

0.004 is under the 0.012 threshold with room to spare and above the 0.001 floor the
settings slider allows, so it stays silent even for a user who has moved the threshold all
the way down.

## Regenerating

`uzbek-0001.wav` is a copy — never regenerate it, or the reference transcript stops
describing it. The other two:

```bash
say -v Samantha -o /tmp/e.aiff "The quick brown fox jumps over the lazy dog."
afconvert -f WAVE -d LEI16@16000 -c 1 /tmp/e.aiff windows/fixtures/audio/english-pangram.wav
```

and the room tone from the LCG in `windows/test/audio/fixtures.test.ts`, which asserts the
committed file still matches what that generator produces.
